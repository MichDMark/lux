# Documentación de LUX

Esta carpeta reúne la información necesaria para instalar, entender y modificar LUX sin depender del historial de la conversación de estudio.

## Ruta de lectura

1. [Arquitectura](architecture.md): componentes, autoridad y flujo de una solicitud.
2. [Configuración y uso](configuration.md): requisitos, variables y comandos.
3. [Desarrollo](development.md): cómo realizar cambios pequeños y verificables.
4. [Seguridad](security.md): políticas del sandbox y límites actuales.
5. [Integración](integration.md): cómo incorporar las interfaces actuales en otro proyecto.

`AGENTS.md` complementa estos documentos con instrucciones obligatorias para agentes que trabajen dentro del repositorio.

## Estado del proyecto

LUX es una aplicación CLI educativa, no un paquete publicado ni una API estable. La documentación describe el comportamiento actual; cualquier cambio de contrato debe actualizar el documento correspondiente en la misma modificación.
